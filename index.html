DynoCo auf diesem Rechner einrichten

Fassung …. Dauert beim ersten Rechner etwa 15 Minuten, danach je Rechner 2 Minuten. Deine Daten bleiben auf euren Rechnern.

Erster Rechner – hier kommt die Datenbank hin

Nur einmal, auf dem Mac, der im Büro an bleibt. Er braucht Internet und ein Administrator-Konto (das Passwort, mit dem du am Mac Programme installierst).

  1. Diese Zeile kopieren:
    bash <(curl -fsSL https://thegamerbeni.github.io/DYNOCO-UPDATER/einrichten.sh)
  2. Das Programm Terminal öffnen: ⌘ + Leertaste drücken, Terminal eintippen, Enter.
  3. Im Terminal einfügen (⌘ + V) und Enter drücken.
  4. Fragt das Terminal nach dem Passwort: das Mac-Passwort eintippen und Enter. Beim Tippen erscheinen keine Zeichen – das ist richtig so.
  5. Zeigt Docker ein Fenster: Bedingungen annehmen, Anmeldung überspringen. Dann warten – das Terminal sagt, was gerade passiert.
  6. DynoCo öffnet sich von selbst. Dort „Erster Rechner“ wählen und den Schritten folgen: Datenbank einrichten, Inhaber-Konto anlegen, Firmenliste einlesen.

Warum eine Zeile im Terminal? So installiert sich DynoCo ohne Warnungen des Macs – und lädt dabei automatisch Docker Desktop, das die Datenbank braucht. Die Zeile darf man ohne Sorge noch einmal ausführen: Bestehende Daten bleiben erhalten.

Weiterer Mac – DynoCo läuft schon im Büro

  1. Auf dem ersten Rechner in DynoCo: Verwaltung → Datenbank → „Verbindungscode für andere Rechner kopieren“, zum Beispiel per Mail an dich schicken.
  2. Auf dem weiteren Mac diese Zeile kopieren und wie oben im Terminal einfügen:
    bash <(curl -fsSL https://thegamerbeni.github.io/DYNOCO-UPDATER/einrichten.sh) weiterer-rechner
  3. DynoCo öffnet sich. „Weiterer Rechner“ wählen, den Verbindungscode einfügen, mit dem Zugangsschlüssel ein Konto anlegen (den Schlüssel erstellt ein Inhaber unter Verwaltung → Zugangsschlüssel).

Beide Rechner müssen im selben Netz sein (z. B. im Büro-WLAN).

Windows-Rechner – DynoCo läuft schon im Büro

Die Datenbank läuft auf einem Mac (siehe Reiter „Mac“). Windows-Rechner verbinden sich damit.

  1. DynoCo für Windows laden
  2. Die geladene Datei öffnen. Zeigt Windows „Der Computer wurde durch Windows geschützt“: auf „Weitere Informationen“ klicken, dann auf „Trotzdem ausführen“. (Die Warnung kommt, weil DynoCo keine gekaufte Signatur hat.)
  3. DynoCo installiert sich und öffnet sich. „Weiterer Rechner“ wählen, den Verbindungscode vom ersten Rechner einfügen und mit dem Zugangsschlüssel ein Konto anlegen.

Updates

Einmal eingerichtet, meldet DynoCo neue Fassungen selbst. Ein Klick auf „Jetzt aktualisieren“ genügt.
